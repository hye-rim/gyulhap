# 결! 합! 🃏

더 지니어스에 4개 시즌 모두 나온 두뇌 게임 「결! 합!」. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`). 규칙은 [나무위키 「결! 합!」](https://namu.wiki/w/결! 합!) 문서를 따랐다.

- **카드**: 27장 = 모양(동그라미·세모·네모) × 배경색(검정·회색·하양) × 도형 색(빨강·노랑·파랑). 한 라운드에 9장을 펼친다(27장 중 무작위).
- **합**: 세 장을 골랐을 때 세 가지 속성이 **각각 모두 같거나 모두 달라야** 한다(하나라도 두 장만 같으면 합이 아님). 27장 안에 합은 117개.
- **컴퓨터와 대결**(쉬움·보통·어려움): 번갈아 한 번씩, 내 차례에 **10초**. 「합!」을 누르면 **5초** 안에 세 장을 고른다. 합 +1, 틀린 합 −1, 이미 나온 합 −1, 5초를 넘기면 −1. 남은 합이 없다고 생각하면 「결!」: 정답 **+3**(라운드 끝), 합이 남아 있으면 −1. 모두가 연달아 **여섯 번** 넘기면 라운드 끝. **10라운드** 점수가 높은 쪽이 승리(동점이면 연장 라운드).
- **블랙 미션**(혼자): **100초** 안에 9장의 합을 모두 찾고 「결!」. 성공하면 다음 판으로 이어지고(연속 기록 저장), 시간이 다 되면 끝. 결을 일찍 누르면 남은 합 수를 알려 주고 계속한다.
- **연습**(`?tutorial=1`): 시간 제한 없이 합 수를 보며 한 판.
- **컴퓨터**: 자기 차례에 실력만큼 남은 합 하나를 찾아 외치고(쉬움 45% · 보통 72% · 어려움 92%), 없으면 결을 외친다(찾지 못하면 넘김). 가끔 실수(틀린 합·남았는데 결)도 한다. 생각하는 시간은 2~5초.
- **조작**: 카드를 눌러 고르고 다시 누르면 취소. 숫자 키 1~9, H(합), G(결), 스페이스(넘기기), M(소리).
- **저장**: 난이도별 전적과 블랙 미션 최고 연속 `gyulhapRec`, 로비 표시용 `gyulhapWins`(승수 + 최고 연속), `gyulhapMuted`.
- 방송 속 변형(관전 게스트·아이템·그랜드 파이널의 해달별 카드·영국판 5라운드 등)은 넣지 않았다.

시험은 `node --test`(`test/logic.test.js`): 카드 27장, 합 117개와 전수 조사 일치, 두 장으로 세 번째 장 정하기, 펼친 카드 안의 합 찾기, 점수 규칙(합·틀림·중복·결 정답/오답·시간 초과), 여섯 번 넘기면 라운드 끝, 차례와 거절되는 행동, 10라운드·연장, 컴퓨터가 늘 합법적 행동만 하는지, 센 컴퓨터가 이기는지, 블랙 미션.
